# KYLA Open-Source Repository Research

Research constraints: prefer free/open-source, low-resource, cloud-first projects that can support a 2012 MacBook Pro (2 cores, 8–16GB RAM) and iPhone 11. Trading focus includes R3 TEMPERANTIA, especially XAUUSD/Nas100 workflows; an open-source project is not assumed to provide market data, broker access, or profitable signals.

## ROUND 1 — Trading / Quant

- **kernc/backtesting.py** — https://github.com/kernc/backtesting.py — What: Lightweight Python framework for quickly backtesting trading strategies and inspecting results. — Room: R3 TEMPERANTIA (strategy research for XAUUSD/Nas100 once OHLCV data is supplied). — **USEFUL** — Reason: Small, notebook-friendly and CPU-suitable for fast hypothesis testing; keep slippage, spread and walk-forward checks explicit.
- **mementum/backtrader** — https://github.com/mementum/backtrader — What: Mature Python backtesting and trading framework with strategy, broker, indicator and analyzer abstractions. — Room: R3 TEMPERANTIA (reusable strategy prototypes and paper/live adapter experiments). — **USEFUL** — Reason: Broad ecosystem and low local resource cost, but its older maintenance profile means pin dependencies and test integrations.
- **QuantConnect/Lean** — https://github.com/QuantConnect/Lean — What: Open-source algorithmic trading engine for research, backtesting and live trading across multiple asset classes. — Room: R3 TEMPERANTIA (cross-asset research and execution architecture). — **USEFUL** — Reason: Strong research/execution model and cloud-first option; local Lean runs may be heavier than the 2012 Mac, so prefer remote execution.
- **TheSnowGuru/PyTrader-python-mt4-mt5-trading-api-connector-drag-n-drop** — https://github.com/TheSnowGuru/PyTrader-python-mt4-mt5-trading-api-connector-drag-n-drop — What: Python/EA connector for MetaTrader 4 and 5 live or paper trading. — Room: R3 TEMPERANTIA (MT5 bridge for broker-side XAUUSD/Nas100 execution). — **USEFUL** — Reason: Directly matches the MT4/MT5 requirement and is lightweight enough to run on a broker/VPS sidecar; license and broker compatibility need review before production.
- **michiTrader/tradetropy** — https://github.com/michiTrader/tradetropy — What: Algorithmic trading framework with order-flow/footprint support plus backtesting and live/replay workflows. — Room: R3 TEMPERANTIA (order-flow confirmation and footprint research). — **USEFUL** — Reason: One of the closest open-source matches for footprint-style analysis; validate its data-feed and instrument assumptions on XAUUSD/Nas100 before adopting.
- **chriskcl/orderflow** — https://github.com/chriskcl/orderflow — What: Builds footprint candles from real-time trades without requiring a heavyweight charting platform. — Room: R3 TEMPERANTIA (streaming order-flow/footprint signals). — **USEFUL** — Reason: Focused and potentially low-resource for a cloud/VPS service; usefulness depends on an available tick/trade feed and careful aggregation validation.
- **freqtrade/freqtrade** — https://github.com/freqtrade/freqtrade — What: Free, open-source Python crypto trading bot with backtesting, hyperoptimization and exchange execution. — Room: R3 TEMPERANTIA (architecture reference only). — **SKIP** — Reason: Its core exchange and market model is crypto-specific, so it has no direct XAUUSD/Nas100 execution value; do not make it the primary stack.
- **ccxt/ccxt** — https://github.com/ccxt/ccxt — What: Unified API library for many cryptocurrency and prediction-market exchanges in multiple languages. — Room: R3 TEMPERANTIA (optional crypto data/exchange adapter). — **SKIP** — Reason: Excellent general exchange plumbing but not a MetaTrader/CFD bridge for XAUUSD/Nas100, and the repository is large for a 2012 Mac; use only if a later crypto lane is intentional.

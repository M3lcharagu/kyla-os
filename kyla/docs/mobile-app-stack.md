Claude Code — AI coding agent that does most of KYLA’s coding, making it a strong fit for rapidly building the product.
Sleek (Sleek AI app design) — turns prompts into full mobile-app designs and exports to Figma or React, giving Claude Code a build-ready starting point.
Expo — ships React Native apps to the Apple App Store and Google Play with one command, avoiding Xcode archives and provisioning profiles for simpler KYLA releases.
Sensor Tower — provides app market data to identify money-making apps and read 1-star reviews, helping KYLA build the version that fixes them.
RevenueCat — handles subscriptions and payments and is free until KYLA makes money, so the paywall can be in place before launch.
Kimi K3 (Moonshot AI) — a possible KYLA brain alternative under evaluation; research status pending.
